Tool Errors importieren

Importiert Werkzeugfehlermeldungen über eine Excel-Datei (.xlsx). Eine zuvor exportierte Datei kann direkt wieder importiert werden. Vorhandene Meldungen werden anhand von error_no und revision aktualisiert.

Gemeinsame Spalten von Export, Import und Vorlage:

  • error_no (Pflichtfeld)
  • revision (optional, Standard: 1)
  • tool_no (Pflichtfeld)
  • error_type (optional)
  • description (optional)
  • tool_status (optional)
  • order_id und machine_id (optional)
