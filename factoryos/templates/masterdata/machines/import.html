Ein Format für Import und Export

Exportierte Maschinendateien können direkt wieder importiert werden. Export und leere Vorlage verwenden dieselben deutschen Spalten. Bearbeite das Blatt Maschinen; ältere Dateien werden weiterhin erkannt.

Leere Zellen löschen optionale Werte. Entfernte Spalten bleiben unverändert. Maschinennummern mit führenden Nullen bitte als Text eingeben. Fehlerhafte Zeilen werden nicht übernommen; gültige Zeilen werden gespeichert.

Existiert eine Maschinennummer bereits, werden die vorhandenen Stammdaten aktualisiert.
Neue Maschinennummern werden automatisch als neue Maschinen angelegt.
Für Spritzgießmaschinen kann als Maschinentyp injection_molding oder Spritzgießmaschine verwendet werden.
